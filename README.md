# AndMTProto (TG WS Proxy для Android)

**Локальный MTProto-прокси** для приложения Telegram на Android, который **ускоряет работу Telegram**, перенаправляя трафик через WebSocket-соединения. Данные передаются в том же зашифрованном виде, а для работы не нужны сторонние серверы. Прокси работает только для Telegram на этом же телефоне.

## Быстрый старт

**Требования:** Android 7.0 или новее, 64-битный процессор (ARM64 или x86_64), установленное приложение Telegram.

1. Перейдите на [страницу релизов](https://github.com/oruviyex18/AndMTProto/releases) и скачайте из раздела **Assets** последний файл `AndMTProto-android-v….apk`.
2. Откройте файл. Если Android спросит, разрешите установку приложений из этого источника (браузера или файлового менеджера) и вернитесь назад.
3. Нажмите **Установить**.

Новые версии устанавливаются поверх старых, настройки сохраняются. Исключение — версия `1.11.2-android.1` и debug-сборки, собранные самостоятельно: они подписаны другим ключом, поэтому их сначала нужно удалить.

### Возможности приложения

- **Запустить / Остановить** — прокси работает в фоне как служба с уведомлением
- **Открыть в Telegram** — автоматически настроить прокси через ссылку `tg://proxy`
- **Копировать ссылку** — скопировать ссылку для подключения
- **Настройки** — порт, секрет, DC → IP, CF-прокси и CF Worker, Fake TLS и другие параметры
- **Лог** — последние строки лога прокси прямо в приложении
- **Плитка в шторке** — включение и выключение прокси из быстрых настроек
- **Запуск при включении телефона** — прокси стартует сам после перезагрузки (после первой разблокировки)
- Подсказки по работе в фоне: оптимизация батареи и автозапуск на Xiaomi (MIUI / HyperOS)

### Настройка Telegram

**Автоматическая настройка**

1. Откройте AndMTProto и нажмите **Запустить**. На Android 13 и новее разрешите уведомления.
2. Нажмите **Открыть в Telegram**, затем в Telegram — **Подключить прокси**.

Если Telegram не открылся, нажмите **Копировать ссылку**, отправьте её себе в «Избранное» в Telegram и нажмите на неё.

**Ручная настройка**

1. Telegram → **Настройки** → **Данные и память** → **Настройки прокси** → **Добавить прокси**
2. Добавьте прокси:
   - **Тип:** MTProto
   - **Сервер:** `127.0.0.1` (или переопределенный вами)
   - **Порт:** `1443` (или переопределенный вами)
   - **Ключ:** `dd` + секрет из настроек AndMTProto (проще скопировать ссылку)

> [!WARNING]
> Пока Telegram настроен на этот прокси, он работает только при запущенном AndMTProto. Если вы выключили прокси, отключите его и в Telegram: **Данные и память** → **Настройки прокси**.

### Работа в фоне

Чтобы система не останавливала прокси:

- Нажмите **Разрешить работу в фоне** в AndMTProto. В открывшемся списке найдите AndMTProto и отключите для него оптимизацию батареи (названия пунктов зависят от телефона).
- **Xiaomi, Redmi, POCO (MIUI / HyperOS):** нажмите **Разрешить работу в фоне**, выберите AndMTProto → «Контроль фоновой активности» → «Нет ограничений». Затем нажмите **Открыть настройки автозапуска** и включите автозапуск для AndMTProto.

## Как это работает

```
Telegram (Android) → MTProto Proxy (127.0.0.1:1443) → WebSocket → Telegram DC
```

1. Приложение поднимает MTProto прокси на `127.0.0.1:1443`
2. Перехватывает подключения к IP-адресам Telegram
3. Извлекает DC ID из MTProto obfuscation init-пакета
4. Устанавливает WebSocket-соединение (TLS) к соответствующему DC через домены Telegram
5. Если WS недоступен (302 redirect) — автоматически переключается на CfProxy / прямое TCP-соединение

Ядро прокси написано на Python и работает внутри приложения через [Chaquopy](https://chaquo.com/chaquopy/), интерфейс — на Kotlin и Jetpack Compose.

> [!IMPORTANT] 
> ### Не грузит фото/видео?
> **Удалите в настройках AndMTProto в поле DC → IP всё, кроме `4:149.154.167.220`**  
> **Если это не помогло, полностью очистите это поле**  
> Подобная проблема встречается на аккаунтах без Premium  
> Если это не помогло, настройте собственный домен по инструкции: [CfProxy.md](./docs/RU/CfProxy.md)

> [!TIP]
> ### Порт уже занят?
> Если на телефоне уже работает другой прокси на порту `1443`, AndMTProto покажет ошибку и кнопку **Использовать порт N**. Нажмите её, затем снова **Открыть в Telegram** → **Подключить прокси**.

## Автоматическая сборка

Android-приложение находится в папке [`android/`](./android/). GitHub Actions workflow ([`.github/workflows/android.yml`](./.github/workflows/android.yml)) запускает тесты, собирает APK и при пуше тега `android-v*` публикует подписанный релиз. Workflow [`.github/workflows/upstream-sync.yml`](./.github/workflows/upstream-sync.yml) ежедневно проверяет изменения в оригинальном проекте и открывает pull request для их переноса.

Поддерживаемые устройства для текущих сборок:

- Android 7.0+ (API 24), ARM64 (`arm64-v8a`) — большинство телефонов
- Android 7.0+ (API 24), x86_64 — эмуляторы и некоторые планшеты
